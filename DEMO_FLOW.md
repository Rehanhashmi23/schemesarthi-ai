# SIH26092 Demo Flow

1. Start FastAPI backend on port 8000.
2. Start React frontend on port 5173.
3. Choose English, Hindi, or Marathi.
4. Load Demo User.
5. Enter or keep the natural-language requirement.
6. Understand Requirement.
7. Find Suitable Schemes.
8. Open an explanation for a matched scheme.
9. Calculate EMI.
10. View partner routing.
11. Review document placeholders.
12. Create a demo application.

This is a hackathon prototype. Scheme and partner records are illustrative demo data.
